# 🥢 TongWei (Đồng Vị - 同味) • Mỹ Vị Quảng Đông

Hệ thống Website Thương Hiệu Ẩm Thực Quảng Đông & Cổng Quản Trị Vận Hành (CMS Portal).

## 🌟 Giới Thiệu
**TongWei (Đồng Vị)** kết tinh tinh hoa mỹ vị Quảng Đông & Trung Hoa truyền thống kết hợp quy chuẩn vận hành F&B hiện đại.
* **Đồng (同):** Sự hòa điệu, đồng lòng, sum vầy.
* **Vị (味):** Hương vị nguyên bản, dư vị tinh tế.

## 🚀 Phân Hệ Hệ Thống

### 1. Trang Web Khách Hàng (Customer Portal)
* **Thực đơn tương tác:** 28+ món ăn chuẩn thực tế với ảnh tách nền chất lượng cao, chia theo 5 danh mục (*Dimsum & Điểm tâm, Hải sản & Cá lăng, Món xào & Nồi đất, Canh tiềm dưỡng sinh, Thức uống*).
* **Thư viện không gian ẩm thực:** 25 ảnh concept chất lượng cao với Lightbox xem chi tiết.
* **Xưởng sản xuất trung tâm HACCP:** Giới thiệu chuỗi cung ứng khép kín và công nghệ cấp đông IQF.
* **Hợp tác nhượng quyền (Franchise):** 3 mô hình đầu tư (*Express, Standard, Flagship*) kèm **Interactive ROI Calculator** tính toán doanh thu/hoàn vốn tự động.
* **Cổng tuyển dụng (Careers):** Đăng tuyển các vị trí F&B kèm form nộp CV trực tuyến.
* **Đặt bàn trực tuyến:** Đặt bàn nhanh và tích hợp thực đơn gọi món trước.

### 2. Cổng Quản Trị Hệ Thống (TongWei Admin Portal / CMS)
* Truy cập tại: `/admin/`
* Bảng điều khiển (Dashboard) thống kê thời gian thực.
* Quản lý Món ăn (Thêm/Sửa/Xóa, đổi giá, đổi ảnh, tích chọn hiển thị lên trang chủ).
* Quản lý Lịch đặt bàn (Tên khách hàng, SĐT, danh sách món đặt trước, trạng thái tiếp nhận).
* Quản lý Cơ sở & Chi nhánh (Thêm/sửa cơ sở mới).
* Quản lý Nhượng quyền (Danh sách đối tác đăng ký Leads).
* Quản lý Tuyển dụng & Thư viện Media.
* Đồng bộ dữ liệu hai chiều tức thì với Website chính.

## 🛠️ Công Nghệ Sử Dụng
* **Frontend:** Semantic HTML5, Vanilla Modern CSS (CSS Variables, Glassmorphism, Micro-animations), Vanilla JavaScript ES6+.
* **Fonts:** `Playfair Display`, `Plus Jakarta Sans` (100% hỗ trợ tiếng Việt đầy đủ).
* **Lưu trữ & Đồng bộ:** LocalStorage Data Engine + JSON sync.
* **Không phụ thuộc framework nặng:** Tải nhanh tức thì, tối ưu SEO và đạt hiệu năng mượt mà trên mọi thiết bị.
